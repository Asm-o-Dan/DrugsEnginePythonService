# DrugsEnginePythonService

DrugsEnginePythonService provides the Python-based vector search and semantic enrichment layer for the Drugs Engine ecosystem.

## Overview
This repository contains the AI and microservice components responsible for embedding generation, vector storage, and semantic retrieval.

## Features
- Vector embedding generation
- Qdrant-based semantic search
- Kafka and RabbitMQ event consumption
- Dockerized deployment for AI services

## Related projects
- DrugsEngine
- DrugsEngine.Web
